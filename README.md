# Form 2 Mathematics Hero Game V48 Stable

## GitHub Pages structure

Upload these items directly to the repository root:

- `index.html`
- `audio/`
- `README.md`

Do not place them inside another folder.

## Student use

1. Open `index.html` or the GitHub Pages URL.
2. Enter the student name once.
3. Tap once anywhere to unlock browser audio.
4. Chapter 1–13 routes use one unified route loader.
5. The same browser remembers the active student.

## Audio

Keep the `audio` folder beside `index.html`.
